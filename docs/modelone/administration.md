# modelOne 系统管理员手册

统一维护企业品牌配置、帮助地址和版权信息。浏览器通过公开的 `/myapp/brand.js` 读取品牌字段；该接口不返回镜像仓库凭据、认证密钥或数据库配置。修改品牌静态资源后重新构建并发布前端。

为用户建立账号、角色和项目组；先用最小权限账号验证菜单及操作权限。LDAP/OIDC/企业认证须在交付环境配置回调、证书及角色映射并单独验收。不要把开发环境默认密码或令牌作为生产凭据。

为 Notebook、训练和服务配置可用节点标签、资源配额、持久卷、运行镜像和拉取 Secret。更新镜像应固定版本，并保留旧标签以支持回滚。先在测试项目运行小规模工作负载，再开放给业务用户。

遇到启动或调度失败，检查应用日志、Pod 事件、数据库连接、存储挂载和镜像仓库可达性。用户界面不应显示堆栈、凭据或企业内部错误细节；完整故障证据保存在受控日志中。
