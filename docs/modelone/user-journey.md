# modelOne 用户旅程与落地页交互设计

日期：2026-09-22。状态：设计稿，与 [space-project-design.md](space-project-design.md) v2 单层空间模型配套。目标：定义登录后的落地解析、四级页面职责、上下文切换与守卫行为，使"我在哪、我能干什么、我上次干到哪"三个问题在首屏内可答。

## 1. 交互原则

1. **确定性落地**：落地页由上下文状态机唯一决定，不做 A/B 或启发式猜测；解析只依赖一次成员资格查询与本地记忆；
2. **恢复优先**：返回用户默认回到上次空间的首页并看到进行中的工作，不强迫重复选择；
3. **角色可见**：入口与首页显式展示"我的角色"与配额用量，先建立能力预期再给操作；
4. **空状态带下一步**：任何空视图必须提供创建/加入/教程三类出口之一，使用品牌化空状态与教程视频资源；
5. **单一上下文源**：会话上下文（服务端）与本地记忆（客户端）以服务端校验为准，本地仅作恢复提示；
6. **共享边界、个人视图**：列表页默认"我创建的"，全空间视图一次点击可达（清空过滤），反之亦然。

## 2. 上下文状态机

状态：
- S0 无空间成员资格；
- S1 有成员资格、无有效上下文；
- S2 有有效空间上下文；
- S3 跨空间上下文（仅 admin / creator 显式开启）。

迁移：

| 从 | 事件 | 到 | 落地页 |
|---|---|---|---|
| 登录成功 | 成员数=0 | S0 | L0 |
| 登录成功 | 本地记忆有效 | S2 | L2 |
| 登录成功 | 记忆失效（被移出/空间删除） | S1 | 提示后 L1 |
| 登录成功 | 无记忆且仅 1 空间 | S2（自动设置） | L2 |
| 登录成功 | 无记忆且多空间 | S1 | L1 |
| S1 | 点击空间卡片/确认继续 | S2 | L2 |
| S2 | 切换器选择其他空间 | S2 | 目标 L2 |
| S2 | 点 Logo/面包屑「项目空间」 | S1 | L1 |
| S2/S1 | admin/creator 开启「全部空间」 | S3 | 跨空间列表视图 |
| 任意 | 退出登录 | 清除 session+记忆 | 登录页 |

记忆有效性=本地 id 仍存在且当前用户仍在成员列表（以一次 `/myapp/spaces/my` 查询校验）。

## 3. 页面定义

### L0 无空间页

目标：获得归属。内容：加入/创建空间指引步骤、管理员与技术支持入口（品牌 supportUrl）、平台级可见区（AIHub 市场浏览、文档）。空状态插画使用品牌资产。动作：发起加入申请（P1 先以支持链接/工单承载，申请流 P3 可选）。

### L1 空间列表（项目空间入口页）

目标：选择上下文。内容块：
1. 我的空间卡片网格：名称、描述、我的角色徽标、成员数、资产总数、配额用量进度条、最近进入时间；creator 卡片带「设置」入口；
2. 最近访问行：跨空间的最近资产（Notebook/流水线/模型）直达链接，支持"不选空间先续作"？——**不允许**：续作必须经上下文，点击资产自动设置其所属空间上下文后跳转（保持单一上下文源）；
3. 搜索与排序（最近/名称/用量）；admin 额外见「全部空间」标签页（非成员空间标注"管理视图"）。

动作：进入空间（S1→S2）、creator 创建空间、admin 跨空间视图。

### L2 空间首页

目标：resume + 概览 + 出发。内容块：
1. 空间头：名称、我的角色、成员头像堆叠（进入成员页）、配额用量摘要（GPU/CPU/存储三条进度）；
2. 我的进行中：在跑 Notebook（含状态点）、运行中流水线、最近编辑资产，按最近活跃排序，限 6 条+「查看全部」；
3. 资产概览卡：数据集/Notebook/流水线/模型/推理/问答配置计数，点击进入对应模块（携带空间上下文）；
4. 快速创建：按角色门禁的创建入口（Notebook/流水线/数据集/模型登记），点击直达对应模块新建表单；
5. 帮助区：品牌教程视频卡（新手视频复用现有资源）+ helpUrl 链接。

空空间变体：块 2/3 替换为「开始第一步」引导卡（创建 Notebook → 跑模板流水线 → 登记模型三步链路）+教程视频。

### L3 模块页

现状通用列表/详情页，附加：
- 默认过滤=我创建的（沿用 default_filter 机制并显式化为"我的/全空间"分段控件）；
- 面包屑：项目空间 / <空间名> / <模块> / <页>；
- 无上下文直达（深链/书签）：按状态机补上下文后渲染，多空间时弹选择框提示"继续到 <资产所属空间>"；
- S3 跨空间视图：列表增加空间列，页头横幅"跨空间视图（只读汇总/按角色）"。

## 4. 顶栏与导航行为

- 切换器（已实现，feat(ui)）语义升级为空间切换器：选项=已加入空间 +（admin/creator）「全部空间」；切换即 S2→S2 并落目标 L2；
- Logo 点击：S2→S1（回空间列表），与面包屑「项目空间」一致；
- 菜单门禁：S0/S1 仅平台域（系统管理、基础设施、空间管理、AIHub 市场、文档、用户中心）；S2 起追加业务五组；S3 同 S2 但列表跨空间；
- 全局 Home 路由改为落地解析器：按状态机重定向，不再承载固定仪表盘内容。

## 5. 角色差异矩阵

| 能力 | dev | ops | creator | admin |
|---|---|---|---|---|
| L1 见已加入空间 | ✓ | ✓ | ✓ | 全部（标注非成员） |
| L1 创建空间 | ✗ | ✗ | ✓ | ✓ |
| L2 快速创建(开发类) | ✓ | ✓ | ✓ | ✓ |
| L2 成员/配额管理入口 | ✗ | ✗ | ✓ | ✓ |
| 全部空间(S3) | ✗ | ✗ | ✓ | ✓（默认开） |
| 干预非成员空间 | ✗ | ✗ | ✗ | ✓ |

## 6. 与现有实现的映射

- 落地解析器：改造 `pages/Home`（现全局首页）为 resolver + L2 空间首页组件；L1 新增 `pages/Spaces`；
- 空间卡片数据：`/project_modelview/space/api/`（P0 菜单页同源）+ 计数聚合接口（P1 新增 `_stats`）；
- 我的进行中：复用现有 demo/shortcut 接口的空间化版本（`/pipeline_modelview/api/my/list/` 等已存在）；
- 守卫：`_info.context_required` + routerConfig 包装组件；
- 切换器：选项源改 type='space'，旧 localStorage 键迁移；
- 空状态/教程：品牌空状态组件 + 现有新手视频资源（资源迁移清单内）。

## 7. 旅程验收用例

1. 新用户（单空间、无记忆）：登录→自动 L2，见引导卡（空空间）或进行中列表；
2. 返回用户：登录→直接 L2 且"我的进行中"与退出前一致；
3. 多空间用户：登录→L1；进入 A→切到 B→回 L1→最近访问行含 A/B 资产且点击自动切上下文；
4. 被移出空间：记忆存在但校验失败→提示+L1，旧书签深链→守卫拦截转 L1；
5. creator：L1 建空间→立即 S2 落新空间 L2（空状态变体）；
6. admin：S3 跨空间视图列表含空间列；干预操作留审计（P3）；
7. 无空间账号：L0 且平台可见区可浏览 AIHub 市场；
8. 退出登录：session 与本地记忆清理，再登录走状态机首行。

每用例纳入 P1 验收，以隔离数据库 + 浏览器脚本（puppeteer-core 既有驱动方式）执行。

## 8. 开放决策点

1. L1 最近访问行的跨空间续作是否接受"自动切上下文"（本设计接受；替代方案：仅展示不可点）；
2. 空间首页"我的进行中"的时间窗（建议 7 天活跃）；
3. 加入申请流是否在 P1 承载（建议 P1 用支持链接，P3 做申请审批流）；
4. S3 跨空间视图对 creator 是否只读（建议只读，写操作需进入具体空间）。
