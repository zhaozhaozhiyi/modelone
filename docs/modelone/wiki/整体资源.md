# 整体资源

入口：服务化-整体资源

包含整体的资源量，占用率，和使用率，以及平台中的所有pod。管理员还可以选中pod，进行批量删除。

![在这里插入图片描述](https://cube-studio.oss-cn-hangzhou.aliyuncs.com/docs/image/ziyaun1.jpg)

同时该界面会弹出每台机器的当前资源占用情况和资源配置情况。

![在这里插入图片描述](https://cube-studio.oss-cn-hangzhou.aliyuncs.com/docs/image/ziyuan2.jpg)
