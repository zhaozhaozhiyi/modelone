# modelOne端口使用

| 端口          | 描述                       | 作用                                                    |
|-------------|--------------------------|-------------------------------------------------------|
| 443         | rancher server管理端口       | 用来管理员通过rancher server 管理集群和扩缩容                        |
| 80          | modelOne的平台端口         | modelOne平台前后端端口                                    |
| 8080        | modelOne开放内部服务和推理服务端口 | 部署的服务可以通过泛域名范文端口，对于需要多端口的服务，使用80和8080作为代理             |
| 10000~20000 | notebook ssh链接端口         | 可以通过每个notebook开放的对应端口，从本地进行ssh远程连接。也可以通过一个代理机器，进行隧道链接 |
| 20000~30000 | 推理服务的开放端口                | 可以通过这个端口来访问自己创建的推理服务                                  |
| 30000~40000 | k8s用户自定义内部服务的开放端口        | 可以通过这个端口来访问自己创建的服务                                    |

# 无法开放多端口的情况

1、`10000~20000` 的notebook ssh服务，可以使用ssh隧道只开放一个端口，参考 ../使用/在线ide.md中的“单端口代理jupyter内部ssh server”部分

2、`20000~30000`的推理服务和`30000~40000`的内部服务，可以使用域名进行代理。参考 ../使用/模型服务.md 中的“域名访问”
