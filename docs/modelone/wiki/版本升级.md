modelOne前后台的部署脚本在install/kubernetes/cube/下

# 升级方法

1、备份数据库，在主机/data/k8s/infra/mysql

2、配置部署后的配置文件infra空间kubeflow-dashboard-config-*的configmap

3、使用新版本部署modelOne前后端 cd install/kubernetes/ && kubectl apply -k cube/overlays

4、等待启动完成，对比下老版本的配置文件和新版本的配置的变化，并根据实际情况修改新部署的配置文件（kubeflow-dashboard-config-*的configmap）。修改配置文件后，重启后台组件
