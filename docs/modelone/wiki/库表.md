# 一、库表功能简介
库表主要是用来记录数据库的元数据的。因为大部分数据库没有一个web界面可以看这些元数据信息，所以才做这么个功能。另外，这个功能还可以随意扩充你想要记录的元数据的字段。

# 二、库表定时更新

需要写个脚本，定时把数据库的库表信息记录到这里，比如每晚查询一下数据库中新增了哪些库表，更改了哪些库表。不限制数据库，什么库表都可以，比如presto、mysql、redis等等。

# 三、库表在线更新

如果不想固定时间查询库表信息更新，可以考虑二开，效果就是实时同步库表元数据。

# 四、 库表信息反向更新

反向同步，也就是在平台新增库表元数据，同步到数据库，也可以二开。
