# modelOne 用户操作手册

1. 登录企业指定的平台地址，进入所属项目。左侧导航底部的项目切换器可全局切换当前空间（项目）：切换后，支持项目过滤的列表页（任务流、Notebook、模型、推理等）默认仅显示该项目的资源，选择「全部项目」恢复全量；选择结果保存在本机浏览器。页面过滤栏中自行添加项目组条件时，以页面条件优先。看不到模块或无法操作时联系管理员核对权限。
2. 数据管理：登记数据集的位置、描述和版本，验证当前运行环境能读取数据。
3. 在线开发：创建 Notebook，选择管理员提供的镜像和资源。代码与数据保存到项目持久目录，停止或重建环境前确认已保存。
4. Pipeline：从任务模板添加节点、填写参数与资源、连接上下游依赖。保存后运行，通过运行记录检查状态和日志。
5. 训练与模型：记录训练输入、参数、产出路径和模型版本。把验证通过的模型登记到模型管理模块。
6. 推理：选择模型与推理镜像，配置启动命令、端口及资源。部署后先测试服务健康及一次实际请求，再提供业务访问。
7. AIHub：按应用说明准备模型与数据资源，再启动相应开发、微调或服务操作。未配置资源的示例不能直接运行。
8. 智能问答：使用管理员配置的模型接口；知识问答还需要可用的知识文件、嵌入服务和已更新的索引。文生图和语音应用直接使用输入文本。
9. 独立编排：Pipeline 与 ETL 编辑器保持既有保存与运行接口。ETL 实际执行能力取决于部署时接入的执行服务。

10. 导航与空间管理：一级任务位于左侧浅色导轨（智能助手、项目空间、数据资产、在线开发、模型训练、服务化，其余收在「更多」）；导轨底部为当前空间与用户入口。项目空间下「空间列表」管理空间名称、描述与资源绑定扩展参数，「成员与配额」管理成员角色与额度；智能助手为导轨首个入口，打开对话工作面。

本手册描述源码中的操作流程；各模块端到端功能尚待目标环境回归验证。
