# modelOne 产品说明

modelOne 是企业级 AI 开发与模型生产平台。平台提供数据集管理、Notebook 在线开发、任务模板、Pipeline 编排、训练运行记录、模型管理、推理服务、AIHub 和智能问答入口。

平台管理服务可运行在 Docker Compose 或 Kubernetes；Notebook、训练及推理等工作负载依赖 Kubernetes 集群、存储和相应任务控制器。部署管理界面不代表计算能力已就绪。

统一品牌源为 `config/modelone.json`，容器环境变量 `MODELONE_*` 可覆盖对应值。企业版权信息只在配置完整时展示。未配置帮助和支持地址时，相关入口不显示。产品名称固定按项目规范采用 modelOne；内部兼容标识另见升级手册。

本版本未新增或验证付费功能、认证协议或模型能力；原有受限功能使用“暂不可用”或“联系管理员开通”说明。
